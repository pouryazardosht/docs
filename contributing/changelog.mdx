## Upcoming

The extension currently has no user-configurable settings. Future versions may add:

- **Customisable emoji** — override the emoji prefix for any logger method or file type to match your team's conventions.
- **Configurable log format** — control the structure of the inserted log statement (e.g. include method name, timestamp, or a custom prefix).
- **Additional file type categories** — extend the file picker to cover more NestJS patterns as the ecosystem evolves.
